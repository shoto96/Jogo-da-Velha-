# 🎮 Jogo da Velha 

## ✨ Destaques

* 4 **temas visuais** (Dark, Light, Black & Red, White & Purple)
* **Modo 2 jogadores (PvP)** e opção contra IA
* **Timer por jogada** configurável
* **Desfazer jogada (undo)**
* **Histórico em tempo real**
* **Ranking Top 20** salvo no LocalStorage
* **Configurações completas** (som, partículas, volume, timer)
* **Persistência automática** de dados

## 🧠 IA do Jogo

* Baseada em **Minimax com Alpha-Beta Pruning**
* Níveis: Fácil, Médio, Difícil e Impossível (IA nunca perde)

## 🚀 Uso

* Basta abrir o `index.html` (funciona offline)

## 🛠️ Tecnologias

* HTML5 + Canvas 2D
* CSS3 (Grid, Flexbox, Glassmorphism)
* JavaScript ES6+
* Web Audio API + LocalStorage
* Sem dependências externas



💡 Um jogo completo, moderno e altamente configurável, elevando o jogo da velha a nível profissional.
